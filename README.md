# Swathi Bangalore Satish Portfolio

Personal portfolio website for Swathi Bangalore Satish, built as a static GitHub Pages site.

**Live site:** [https://swathiblrs.github.io](https://swathiblrs.github.io)

## Overview

This portfolio presents my background as a Software Engineer with experience in backend development, AI-assisted automation, RAG applications, distributed network simulation, testing, and system reliability.

The site is intentionally lightweight: plain HTML, embedded CSS, and a small JavaScript animation on the home page. It can be opened directly in a browser or served through any static file server.

## Pages

- [Home](index.html): profile intro, background, skills summary, and contact links.
- [Skills](skill.html): technical skills across programming, AI/GenAI, backend, data, testing, DevOps, and tools.
- [Experience](experience.html): professional experience at the University of Tennessee, Nokia, and BEML.
- [Education](education.html): academic background and coursework.
- [Projects](project.html): selected software, AI/RAG, networking, and data projects.
- [Certificates](certification.html): certification links and credentials.

## Run Locally

Because this is a static site, you can open `index.html` directly in a browser.

For a local server:

```bash
python3 -m http.server 8765
```

Then open:

```text
http://localhost:8765
```

## Deployment

This repository is deployed with GitHub Pages. Updates pushed to the `main` branch are published at:

[https://swathiblrs.github.io](https://swathiblrs.github.io)

If changes do not appear immediately, hard refresh the browser or wait a few minutes for GitHub Pages/CDN caching to update.

## Maintenance Notes

- Keep navigation links consistent across all HTML pages.
- Use `skill.html`, `project.html`, and `certification.html` as the canonical filenames.
- Update resume/profile language in `index.html`, `experience.html`, `skill.html`, and this README together when background changes.
- Avoid adding dependencies unless the site is intentionally migrated to a framework.
